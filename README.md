# ShirtShop — เว็บขายเสื้อออนไลน์ด้วย Flutter

โปรเจกต์ตัวอย่าง Flutter (รันเป็นเว็บได้ผ่าน Flutter Web) สำหรับร้านขายเสื้อออนไลน์
ประกอบด้วย: หน้ารายการสินค้า, ค้นหา/กรองตามหมวดหมู่, หน้ารายละเอียดสินค้า (เลือกไซส์/สี/จำนวน),
ตะกร้าสินค้า และหน้าชำระเงิน (mock — ยังไม่เชื่อมระบบชำระเงินจริง)

## โครงสร้างไฟล์

```
shirt_shop/
├── pubspec.yaml
└── lib/
    ├── main.dart                     # entry point
    ├── models/product.dart           # โมเดล Product และ CartItem
    ├── data/mock_products.dart       # ข้อมูลสินค้าจำลอง (แก้ไข/เพิ่มสินค้าที่นี่)
    ├── providers/cart_provider.dart  # จัดการ state ตะกร้าสินค้า
    ├── widgets/product_card.dart     # การ์ดแสดงสินค้าในหน้า grid
    └── screens/
        ├── home_screen.dart          # หน้ารายการสินค้า
        ├── product_detail_screen.dart# หน้ารายละเอียดสินค้า
        ├── cart_screen.dart          # หน้าตะกร้าสินค้า
        └── checkout_screen.dart      # หน้าชำระเงิน
```

## วิธีรัน (ต้องติดตั้ง Flutter SDK บนเครื่องของคุณก่อน)

1. ติดตั้ง Flutter: https://docs.flutter.dev/get-started/install
2. คัดลอกโฟลเดอร์ `shirt_shop` ไปไว้ในเครื่อง แล้วเปิด terminal ในโฟลเดอร์นั้น
3. ติดตั้ง dependencies:
   ```bash
   flutter pub get
   ```
4. เปิดใช้งาน Flutter Web (ครั้งแรกครั้งเดียว):
   ```bash
   flutter config --enable-web
   ```
5. รันเป็นเว็บ:
   ```bash
   flutter run -d chrome
   ```
   หรือ build เป็นเว็บสำหรับ deploy จริง:
   ```bash
   flutter build web
   ```
   ไฟล์ที่ build เสร็จจะอยู่ที่ `build/web` สามารถอัปโหลดขึ้น hosting ใดก็ได้ เช่น
   Firebase Hosting, Netlify, Vercel, GitHub Pages

## ฟีเจอร์เปลี่ยนรูปสินค้าในเว็บ (ใหม่)

ที่หน้ารายละเอียดสินค้า จะมีปุ่มรูปดินสอ (✏️) ลอยอยู่มุมขวาล่างของรูปสินค้า
กดแล้วเลือกรูปจากเครื่องได้เลย รูปจะถูกบันทึกไว้ใน localStorage ของเบราว์เซอร์
เปิดแอปใหม่ก็ยังเห็นรูปเดิมอยู่ (เฉพาะเบราว์เซอร์/เครื่องเดียวกัน)

⚠️ **ข้อจำกัดสำคัญ**: เพราะแอปนี้ยังไม่มี backend/ฐานข้อมูลกลาง รูปที่เปลี่ยน
จะเห็นเฉพาะคนที่กดเปลี่ยนเท่านั้น **ไม่ได้ไปอัปเดตให้ผู้เข้าชมคนอื่นเห็นด้วย**
ถ้าต้องการให้ทุกคนเห็นรูปเดียวกัน (เหมาะกับใช้งานจริงเป็นร้านค้า) ต้องเชื่อมกับ
backend จริง เช่น Firebase Storage + Firestore — บอกได้ถ้าต้องการให้ช่วยทำส่วนนี้ต่อ

## Deploy ขึ้นเว็บจริงให้ทุกคนเข้าถึงได้ (ไม่ต้องรันเองอีก)

ใช้ **Netlify Drop** ซึ่งฟรีและไม่ต้องติดตั้งอะไรเพิ่ม:

1. Build เว็บเวอร์ชัน release:
   ```powershell
   flutter build web --release
   ```
   ไฟล์ที่ build เสร็จจะอยู่ที่โฟลเดอร์ `build\web`

2. เปิดเบราว์เซอร์ไปที่ **https://app.netlify.com/drop**

3. เปิด File Explorer ไปที่ `shirt_shop\build\web` แล้วลาก**ไฟล์ทั้งหมดในโฟลเดอร์นี้**
   (ไม่ใช่ตัวโฟลเดอร์ `web` เอง — ต้องลากไฟล์ข้างในทั้งหมด เช่น `index.html`, `main.dart.js` ฯลฯ)
   ไปวางในหน้าเว็บ Netlify

4. รอสักครู่ Netlify จะสร้างลิงก์สาธารณะให้ทันที เช่น `https://random-name-123.netlify.app`
   ลิงก์นี้เปิดได้จากทุกที่ ทุกอุปกรณ์ ไม่ต้องรัน `flutter run` อีกแล้ว

5. (ถ้าอยากได้ชื่อลิงก์ที่จำง่ายขึ้น หรือแก้ไซต์ในอนาคตได้) กด "Sign up" สมัครฟรี
   แล้วสามารถเปลี่ยนชื่อ subdomain หรือเชื่อมโดเมนของตัวเองได้ที่หน้า Site settings

**หมายเหตุ**: ทุกครั้งที่แก้โค้ดแล้วอยากอัปเดตเว็บที่ deploy ไปแล้ว ต้อง `flutter build web --release`
ใหม่ แล้วลากไฟล์ไปวางที่ Netlify อีกครั้ง (หรือถ้าสมัครสมาชิกแล้วสามารถลากทับไซต์เดิมได้เลย)



สิ่งที่ตัวอย่างนี้ยังไม่มี (เพราะเป็น demo แบบ mock ข้อมูลในเครื่อง ไม่มี backend):

- **ฐานข้อมูลสินค้าจริง**: ปัจจุบันสินค้าอยู่ใน `mock_products.dart` แบบ hardcode
  แนะนำให้เชื่อมกับ backend เช่น Firebase Firestore, Supabase หรือ REST API ของคุณเอง
- **ระบบสมาชิก/ล็อกอิน**: ยังไม่มีหน้า login/สมัครสมาชิก
- **ระบบชำระเงินจริง**: หน้าชำระเงินตอนนี้เป็นแค่ฟอร์ม mock ที่กด "ยืนยัน" แล้วเคลียร์ตะกร้า
  หากต้องรับเงินจริงต้องเชื่อม payment gateway เช่น Omise, 2C2P, PromptPay QR, Stripe
- **ระบบจัดการออเดอร์ฝั่งแอดมิน**: สำหรับดูออเดอร์ อัปเดตสถานะจัดส่ง ฯลฯ
- **รูปภาพสินค้าจริง**: ตอนนี้ใช้รูป placeholder จาก picsum.photos ควรเปลี่ยนเป็นรูปสินค้าจริง
  (อัปโหลดไปยัง cloud storage แล้วใส่ URL ใน `imageUrl`)

หากต้องการให้ช่วยต่อในส่วนไหน (เช่น เชื่อม Firebase, ทำระบบล็อกอิน, หรือเชื่อม payment gateway)
บอกได้เลยครับ
